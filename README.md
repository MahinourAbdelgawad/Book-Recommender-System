# Book Recommender System Using Machine Learning


## Data Cleaning and Pre-Processing Scripts
| Notebook | What it does | 
|---|---|
| 1_check_datasets.ipynb | Inspects the raw files and their schemas |
| 2_extract_books.ipynb | Extracts and cleans the book table | 
| 3_extract_interactions.ipynb | Loads the interactions, maps book IDs, checks duplicates |
| 4_prepare_sample.ipynb | 20-core filtering, user sampling, second filter, author and genre joins | 
| 5_data_split.ipynb | Train/val/test split, train-only user and book features, missing-value filling | 
| 6_preprocess_features.ipynb | Doc2vec, one-hot encoding, scaling, correlation analysis, export | 


## Dataset

The cleaned dataset is dataset/cleaned_dataset.parquet
(962,899 rows, 101 columns)
